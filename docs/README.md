# Verdyx Documentation

This folder contains the operational docs for local development, deployment, architecture, APIs, and security.

## Quick Navigation

- `API.md`: Human-readable API guide.
- `api/openapi.yaml`: OpenAPI 3.0 spec (starter set of core routes).
- `api/examples/`: Request payload examples.
- `api/postman/`: Postman collection.
- `architecture/`: System design and request/data flow.
- `deployment/`: Local, Kubernetes, and production runbooks.
- `development/`: Code style, contributing, and testing guidance.
- `security/`: Threat model and incident response playbooks.

## Start Here

1. Local setup: `docs/deployment/local-setup.md`
2. Test workflow: `docs/development/testing-guide.md`
3. API usage: `docs/API.md`
4. Production rollout: `docs/deployment/production.md`
